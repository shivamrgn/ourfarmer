CONFIRMED BUGS & RESOLUTIONS (PHASES 22 & 23)
================================================================================

BUG-01: Automatic 1-Minute Session Expiry in Main App
- Severity: P1 (Major Feature / Auth Consistency)
- Module: FieldWise_main/src/context/AuthContext.tsx
- Cause: Session expiration was checked only on component mount and on cross-tab storage events. If a user remained on the dashboard without reloading, the session never expired.
- Fix: Added an active useEffect timeout listener measuring expiry against Date.now() that automatically invokes logout() and redirects to ?logout=true upon expiry.

BUG-02: Prediction API Validation Error Masking
- Severity: P1 (Major Feature / Error Visibility)
- Module: FieldWise_main/src/lib/api.ts
- Cause: predictApi.predict() caught all Axios errors indiscriminately. When the backend returned HTTP 400 Bad Request with validation details, the catch block swallowed the error and substituted offline_ml_engine with success: true.
- Fix: Updated predictApi.predict to rethrow HTTP 4xx client errors, reserving offline engine fallback strictly for network or server unavailability.

BUG-03: Backend Prediction Token Requirement
- Severity: P1 (API Integration)
- Module: FieldWise_main/backend/src/routes/predict.js & middleware/auth.js
- Cause: POST /api/predict required a backend JWT token, while the frontend authenticates via Firebase / local sessions, causing all prediction requests to fail with 401 Unauthorized.
- Fix: Added optionalAuth middleware that attaches user tokens if provided while allowing valid farm prediction payloads through.

BUG-04: Client-Side Input Validation in Crop Recommendation
- Severity: P2 (Input Validation)
- Module: FieldWise_main/src/components/modules/CropRecommendation.tsx
- Cause: Missing client-side boundary checks prior to dispatching predictions to the backend, and missing validation error parsing from the API response object.
- Fix: Added client-side range checks (Rainfall 0-1000, Temp 0-50, Humidity 0-100, NPK 0-300, pH 3-10) and formatted validation error messages.

BUG-05: Fertilizer Recommendation Boundary Checks
- Severity: P2 (Input Validation)
- Module: FieldWise_main/src/components/modules/FertilizerRecommendation.tsx
- Cause: Did not validate against negative NPK nutrient values or invalid pH bounds outside 0–14.
- Fix: Added validation checks rejecting negative NPK values and ensuring pH falls between 0 and 14.

BUG-06: Farm Profile Validation on Save
- Severity: P2 (Data Integrity)
- Module: FieldWise_main/src/pages/Profile.tsx
- Cause: Profile form saved directly without verifying required fields or checking for negative/invalid numeric entries.
- Fix: Added validation guards in handleSave requiring Full Name, Mobile Contact, State, District, positive Farm Size (> 0), Primary Soil Type, valid pH (0–14), and non-negative NPK before saving.

BUG-07: Backend Missing Test Suite
- Severity: P2 (Build & Test Health)
- Module: FieldWise_main/backend/package.json
- Cause: "npm test" script referenced a non-existent test file src/tests/auth.test.js, causing MODULE_NOT_FOUND.
- Fix: Implemented src/tests/auth.test.js smoke and integration test covering SQLite database initialization and the predictor calculation engine.
